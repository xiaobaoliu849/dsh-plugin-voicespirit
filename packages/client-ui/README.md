# @deepseek-ai/dsh-client-ui-voicespirit

English | [中文](README.zh.md)

## Summary

`dsh-client-ui-voicespirit` is the client UI plugin for VoiceSpirit duplex voice calls in DeepSeek Harness. It provides composer action buttons, a floating call dock, realtime audio visualizers, and plugin configuration cards.

## Model Experience

None, as this package is a browser-side UI plugin that registers no model-facing prompts.
